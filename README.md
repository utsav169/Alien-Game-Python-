# Alien-Game-Python-
Alien Invasion is a classic arcade-style shooter game developed using Python and the Pygame library. The player controls a ship that can move horizontally across the screen and fire bullets to eliminate waves of incoming aliens.

---

## 🎮 Features

- Smooth ship movement with keyboard input.
- Bullets with collision detection to destroy aliens.
- Aliens move in fleets and descend after reaching screen edges.
- Scoreboard displaying current score, high score, level, and remaining ships.
- "Play" button to start/restart the game.
- Game speeds up as the player advances levels.

---

## Technologies Used

- Python 3.x
- Pygame
